Summary: All test cases in this fixture have HIGH CONTRAST (white text stays at least 7:1 on every background). However, automated tools should flag these for manual testing due to:

  • Complex backgrounds (images, gradients) where contrast may vary across the surface
  • Z-index stacking contexts where positioned elements with z-index may have unpredictable backgrounds due to layering (Note: transparent backgrounds WITHOUT z-index are fine and should NOT be flagged)
  • Text overflow where some text extends beyond defined background container
  • CSS animations where contrast changes over time
  • Combined factors that make reliable automated calculation impossible
Expected Result: Warning/Manual Testing Required (e.g., WarnTextContrastCannotCalculate)

Important: Backgrounds use distinct dark hues rather than flat black so the gradient/pattern/image in each case is actually visible for manual review; the engine flags these on background type, not colour. Simple transparent backgrounds without z-index are NOT included here because they can be reliably calculated by walking up the DOM tree to find the effective background color.
